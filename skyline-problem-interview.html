The Skyline Problem: Explaining the Sweep Line and Heap in a Coding Interview

The skyline problem is a classic "hard" question because it combines three ideas at once: turning shapes into events, sweeping left to right, and keeping the current maximum height in a heap. If you can narrate those three steps clearly, the code almost writes itself.

1. Turn buildings into events

Each building [left, right, height] produces a start event at left and an end event at right. A common trick is to store start events with a negative height so that sorting by (x, height) processes taller starts first and avoids duplicate key points at the same x.

2. Sweep with a max-heap and lazy deletion

import heapq

def get_skyline(buildings):
    events = []
    for l, r, h in buildings:
        events.append((l, -h, r))   # start: negative height, remember end
        events.append((r, 0, 0))    # end marker
    events.sort()

    result = []
    heap = [(0, float('inf'))]      # (negative height, end x)
    for x, neg_h, r in events:
        if neg_h:
            heapq.heappush(heap, (neg_h, r))
        while heap[0][1] <= x:      # lazily drop buildings that ended
            heapq.heappop(heap)
        height = -heap[0][0]
        if not result or result[-1][1] != height:
            result.append([x, height])
    return result

3. What to say while you code

  • Why lazy deletion: Python's heap cannot remove an arbitrary element in O(log n), so we leave ended buildings in place and pop them only when they reach the top.
  • Key point rule: we only output a point when the current max height changes. That one sentence explains the whole if at the bottom.
  • Complexity: 2n events, each pushed and popped at most once, so O(n log n) time and O(n) space.
  • Alternatives: divide and conquer (merge two skylines like merge sort) or a sorted multiset in languages that have one (TreeMap in Java).

4. Test cases worth mentioning

  • Two buildings with the same left edge and different heights.
  • A building that ends exactly where another starts at the same height (no duplicate point).
  • Fully nested buildings.
